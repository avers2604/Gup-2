## Отклонения от исходного списка Заказчика (риск-ревью)

**Django: 6.1 → 5.2 LTS.** Django 6.1 — обычный feature-релиз с коротким
окном поддержки (до выхода следующего релиза); 5.2 — LTS-ветка с
поддержкой до апреля 2028. Для системы, которая после сдачи будет жить в
изолированном контуре с редкими обновлениями (ТЗ: «доступность без
внешних каталогов», нет постоянного канала апдейтов), LTS радикально
снижает риск остаться на неподдерживаемой версии до следующего окна
обслуживания. Требование `condition=` вместо устаревшего `check=` у
`CheckConstraint` (внесено при переходе на 6.1) оставлено как есть —
это forward-совместимое написание, работающее в 5.2 и в будущих версиях
одинаково.

Если Заказчиком версия 6.1 зафиксирована по внешней причине (например,
уже согласована с ОС-дистрибутивом/реестром пакетов Astra Linux или РЕД
ОС и завязана на другие компоненты), это отдельный повод вернуться к
6.1 — тогда нужно явное подтверждение, что для 6.1 обеспечена
поддержка минимум на срок эксплуатации до следующего планового
обновления.

**Python: 3.14.7 не понижен, но помечен как неподтверждённый.** 3.14 —
самая новая ветка Python на момент подготовки ТЗ; экосистема (сборки
`psycopg[binary]`, `argon2-cffi`, `django-storages`/`boto3`, системные
пакеты Astra Linux/РЕД ОС) может не иметь готовых колёс/пакетов под неё
на момент развёртывания. В песочнице сборки каркаса доступен только
Python 3.13 (3.14 недоступен из-за сетевых ограничений на deadsnakes
PPA) — весь код в этом репозитории проверен на 3.13. Рекомендация:
подтвердить доступность 3.14.7 в целевом дистрибутиве ОС и совместимость
всех зависимостей до конца Этапа 1; если подтверждения нет к началу
Этапа 2 — сознательно зафиксировать 3.13 как рабочую версию.

## Лицензии и поддержка (требуют решения Заказчика/юридической службы)

- **Redis 8.x — лицензия AGPLv3** (Redis Ltd вернула Redis на открытую
  лицензию начиная с версии 8, после периода RSAL/SSPL у 7.4). Redis
  используется здесь только как инфраструктурная зависимость (очереди
  Celery), не встраивается и не модифицируется в составе продукта — по
  общей практике это не создаёт copyleft-обязательств для АИС «БЗ ГЭТ»
  как отдельного процесса, но для государственного заказчика
  целесообразно формальное заключение юридической службы. Альтернатива
  при неприемлемости AGPL — **Valkey** (форк Redis под BSD-3, поддержан
  Linux Foundation, протокол-совместим).
- **MinIO — лицензия AGPLv3** для community-редакции; коммерческая
  редакция **AIStor**, указанная Заказчиком, подразумевает лицензионный
  договор с поставщиком (Nutanix/MinIO), снимающий вопрос AGPL для
  распространения. Нужно подтвердить у закупочной службы, что договор
  поддержки/лицензия AIStor оформлены — иначе фактически будет
  разворачиваться community-сборка с открытыми лицензионными
  вопросами.
- **ClamAV, Prometheus, Grafana, PostgreSQL, PgBouncer, etcd, nginx,
  pgBackRest, Tesseract** — постоянные открытые лицензии (GPLv2, Apache
  2.0/AGPLv3 для Grafana, PostgreSQL License, ISC/BSD и т.п.) без
  известных рисков для встраивания как инфраструктурных зависимостей;
  отдельного юридического ревью не требуют.

## Локальная разработка в этой сессии

Песочница, в которой велась разработка, не имеет доступа к пакетам
PostgreSQL 18 (в apt только 16-я ветка), к Python 3.14 (deadsnakes PPA
недоступен из контура) и к Docker Hub/Quay (нет демона Docker — образы
из `docker-compose.yml` не подтягивались и не проверялись «вживую», только
`docker compose config` на синтаксис). Проверка каркаса в этой сессии
проведена на:

- Python 3.13.12 (ближайшая доступная версия);
- PostgreSQL 16.13 (схема не использует возможностей, специфичных для
  PostgreSQL 17/18 — `tstzrange`, `EXCLUDE USING gist`, `btree_gist`
  поддерживаются начиная с PostgreSQL 9.2);
- Django 5.2.17, Gunicorn 23.0.0.

`manage.py check`, `manage.py migrate` (включая exclusion constraint по
ТЗ 4.2.3) и запуск под Gunicorn прошли чисто. Перед вводом в опытную
эксплуатацию необходимо повторить проверку на целевых версиях
PostgreSQL 18.6, подтверждённой версии Python (3.13 или 3.14.7) и
вживую поднятых образах etcd/PgBouncer/ClamAV/Prometheus/Grafana.
