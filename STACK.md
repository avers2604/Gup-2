## Локальная разработка в этой сессии

Песочница, в которой велась разработка, не имеет доступа к пакетам
PostgreSQL 18 (в apt только 16-я ветка) и к Python 3.14 (deadsnakes PPA
недоступен из контура). Проверка каркаса в этой сессии проведена на:

- Python 3.13.12 (ближайшая доступная версия, удовлетворяющая `Django>=6.1`
  требованию `Python ≥ 3.12`);
- PostgreSQL 16.13 (схема не использует возможностей, специфичных для
  PostgreSQL 17/18 — `tstzrange`, `EXCLUDE USING gist`, `btree_gist`
  поддерживаются начиная с PostgreSQL 9.2).

`manage.py check` и `manage.py migrate` (включая exclusion constraint по
ТЗ 4.2.3) прошли чисто под Django 6.1.1 на PostgreSQL 16. Перед вводом в
опытную эксплуатацию необходимо повторить проверку на целевых версиях
PostgreSQL 18.6 и Python 3.14.7.
